# 02 — Rodar pelo Claude Code

Abra a pasta deste repositório no **Claude Code autenticado** e cole o texto abaixo. O código já está implementado; não é uma tarefa para você programar.

Repositório: https://github.com/ibcappainstituto-arch/agente-whatsapp

```text
Prepare e conduza este agente de WhatsApp já implementado nesta pasta. Leia você o README e os guias técnicos; não me peça para desenvolver adaptadores, instalar um aplicativo Windows ou usar Docker.

Aproveite minha pasta conhecimento_agente com os seis Markdown já preparados. Preserve os originais, não refaça tudo nem peça CSV manual. Aponte apenas lacunas e peça minha aprovação dos serviços, preços e condições.

Confira os programas e o Claude autenticado por assinatura, sem API paga nem contornar proteções. Use o código existente para preparar a ponte local do WhatsApp e o agente. Se faltar dependência, explique e peça autorização; não altere o sistema ou a política de execução. Peça também autorização específica antes de gravar chave/configuração, parear e habilitar respostas.

Quando eu autorizar o teste, abra o visualizador QR somente na minha tela privada, sem enviar imagem pelo chat nem projetar a janela. Use apenas um contato de teste que consentiu. Não faça campanhas, mensagens iniciais ou retomadas.

Acompanhe duas trocas: pergunta enviada pelo outro telefone, resposta gerada pelo Claude e recebida naquele telefone. Não diga que funciona antes dessa confirmação. Se houver falha, informe a etapa exata e pare; não repita envio incerto. Ao terminar, encerre os processos que iniciou, salvo minha autorização para mantê-los.
```
